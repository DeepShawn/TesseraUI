TesseraUI v0.1

APPLE · ANDROID · WINDOWS · WEB

一套 token，四端一致

TesseraUI 是一套干净、圆润、流畅的 UI 设计标准库。所有颜色、字体、间距、圆角、阴影和动效都写在一份 JSON 里，自动导出到 SwiftUI、Jetpack Compose、WinUI 3 和 Web；浅色、深色、增强对比度只靠切换 token。这一页本身就是用 Web 端的组件搭出来的。

颜色

语义 token，组件只引用这一层。切换右上角的主题和对比度，色值实时变化；240 项对比度检查全部通过 WCAG AA。

字体

英文和数字用 Plus Jakarta Sans；中文用各平台的系统黑体（苹方 / 思源黑体 / 微软雅黑）。只用 400 和 600 两种字重。

圆角

单行控件一律胶囊形；支持的浏览器上自动使用连续曲率（squircle）。

阴影

深色模式阴影改为 40% 不透明度，并补 1px 描边。

位移和缩放都用弹簧；动画随时可以打断，松手时继承手指的速度。

24×24 画布、1.5px 圆头线条、单色 currentColor；实心版加 -fill 后缀。v0.1 先画了 个，首批目标约 150 个。

组件

底层沿用原生元素（button、input、dialog），保留键盘、读屏和输入法支持；外观全部重画。
