TesseraUI 取意马赛克镶嵌：每个控件都是一块打磨圆润的釉面砖，成组时留出砖缝，按下去会微微下沉。石灰白的底、孔雀釉的主色、五种矿物颜料，配一套软衬线标题。一份设计令牌导出到 Apple、Android、Windows 与 Web 四个平台，浅色、深色与增强对比度只靠切换令牌。所有动效都用弹簧，可以随时打断，松手时继承手指的速度。

容器 · 安全区

Container · SafeArea

.ts-container：内容最宽 1200 居中，平板页边距 32、手机 16。
.ts-safe-area / .ts-safe-top / .ts-safe-bottom：为刘海和底部手势条留出空间。本页的提示消息、底部抽屉、悬浮按钮都已使用。

移动端手势

SwipeAction、PullToRefresh、InfiniteScroll、IndexBar。建议用手机打开本页体验；桌面上左滑和索引栏也可以用鼠标拖。
