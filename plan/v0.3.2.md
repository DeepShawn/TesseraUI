# v0.3.2：补齐 v0.3.1 的短板

预计 1～2 周。小版本，不增加新组件。

## 1. 输入框与浮层自检（已完成）

按“发布前自检”的要求，对全部输入框在三种外观 × 浅色 / 深色 × 桌面 / 手机下逐项截图检查（14 个输入框 × 12 种组合 × 未聚焦 / 聚焦，共 336 张），发现并修复：

- [x] 多行文本框聚焦时出现双重框：外层光晕之外，内部 `<textarea>` 还画了一个方形焦点框（三种外观都有）
- [x] 圆融 / 流韵：数字步进器聚焦时只有中间一段变白，两边按钮仍是灰色；现在整块一起变成砖面色
- [x] 圆融 / 流韵：“搜索 + 排序”这类合成一整块的组合输入，聚焦光晕只包住搜索框、右侧是直角；现在光晕包住整块
- [x] 下拉列表（自动补全）在手机上会盖住输入框：上下空间都不够时会被硬塞进屏幕。现在放到空间较大的一侧并压缩高度（内部滚动），永远不盖住输入框
- [x] 下拉列表、日期等选择器面板、气泡卡片、菜单在页面滚动或手机软键盘弹出时不跟着输入框走；新增 `follow()`，滚动、窗口变化、visualViewport 变化时重新定位
- [x] 输入框放进弹性布局时被原生 `<input>` 约 20 个字符的固有宽度撑开，窄屏上把卡片撑出屏幕
- [x] 验证码 6 格在 320px 宽的屏幕上放不下；每格改为可在 32～48px 之间收缩
- [x] 分页在很窄的屏幕上撑宽页面；改为横向滑动
- [x] 预览页在手机上横向溢出（顶栏切换按钮不能换行、卡片网格被内容撑开、手机样机固定 360 宽）

新增的自动化检查（每项都截图）：

- [x] 输入框聚焦时内部原生控件不画焦点框
- [x] 手机上自动补全的下拉列表不盖住输入框，滚动后仍贴着输入框
- [x] iPhone SE（320 宽）与 iPhone 13（390 宽）上首页、组件总览都不横向溢出
- [x] 交互测试的每一项都截图，三种外观各一组，CI 上传为 `e2e-screenshots`
