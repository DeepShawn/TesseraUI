# TesseraUI 后续计划

本计划已于 2026-11-18 确认，是 v0.3.1 之后各版本的工作安排。进度在每个版本完成后更新；已完成的条目打勾，并注明实际完成情况。

## 总原则

- **三种外观同时推进**：拼贴（tile）、圆融（round）、流韵（flow）共用全部组件代码。新增或修改任何组件时，三种外观同时适配、同时测试，不单独为某一种外观发版。
- **每项测试都截图**：Web 端交互测试每一项结束后自动截图，三种外观各一组，CI 上传为 `e2e-screenshots`；Android 截图测试覆盖三种外观 × 浅色 / 深色。新增测试时同样要截图。
- **发布前自检**：每次发布前，所有输入框都要在三种外观 × 浅色 / 深色 × 桌面 / 手机下逐项截图检查（未聚焦、聚焦两种状态），手机页面不能横向溢出。
- 版本号遵循语义化版本；1.0 之前次版本号可能包含不兼容变更，会在更新日志中注明。
