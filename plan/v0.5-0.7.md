# v0.5.0～v0.7.0：原生三端补齐其余约 60 个组件

Web 端已有全部 84 个组件。原生三端（Android、Apple、Windows）分三批补齐其余约 60 个，每批 3～4 周。每个组件都同时做三种外观、三端截图测试与交互测试，并达到 v0.4.0 的完成标准。

## v0.5.0：表单与输入

- [x] ButtonGroup、SplitButton、FAB、Link
- [x] TextArea（自动高度）、PasswordField（显示切换、大写锁定提示）
- [x] NumberInput（长按连续调整、全角数字）、OTPInput（粘贴、短信自动填充）
- [x] Autocomplete、TagInput
- [x] Slider（单值 / 范围）、Rating、FileUpload
- [x] DatePicker、TimePicker、DateRangePicker、WheelPicker、ColorPicker、Calendar
- [x] Form、FormField、FieldGroup（中文校验提示）

完成于 2026-11-19。Windows 截图与 v0.4.0 一样只有浅色 / 深色，没有单独的增强对比度截图。iOS 已知问题（下拉选择与更多菜单没有读屏名称）一并修复。

## v0.6.0：数据展示

- [x] Table（排序、筛选、多选、固定列、窄屏卡片布局）
- [x] Tree、Accordion
- [x] Tooltip、Popover
- [x] DescriptionList、Timeline、Stat
- [x] Carousel、ImageViewer（缩放、平移、下滑关闭）
- [x] EmptyState、CodeBlock、Kbd
- [x] Progress（线形 / 环形）、Spinner、Result、Banner

完成于 2026-11-22。Windows 截图仍只有浅色 / 深色；Windows 轮播不支持露出前后两张。
