# v0.5.0～v0.7.0：原生三端补齐其余约 60 个组件

Web 端已有全部 84 个组件。原生三端（Android、Apple、Windows）分三批补齐其余约 60 个，每批 3～4 周。每个组件都同时做三种外观、三端截图测试与交互测试，并达到 v0.4.0 的完成标准。

## v0.5.0：表单与输入

- [ ] ButtonGroup、SplitButton、FAB、Link
- [ ] TextArea（自动高度）、PasswordField（显示切换、大写锁定提示）
- [ ] NumberInput（长按连续调整、全角数字）、OTPInput（粘贴、短信自动填充）
- [ ] Autocomplete、TagInput
- [ ] Slider（单值 / 范围）、Rating、FileUpload
- [ ] DatePicker、TimePicker、DateRangePicker、WheelPicker、ColorPicker、Calendar
- [ ] Form、FormField、FieldGroup（中文校验提示）

## v0.6.0：数据展示

- [ ] Table（排序、筛选、多选、固定列、窄屏卡片布局）
- [ ] Tree、Accordion
- [ ] Tooltip、Popover
- [ ] DescriptionList、Timeline、Stat
- [ ] Carousel、ImageViewer（缩放、平移、下滑关闭）
- [ ] EmptyState、CodeBlock、Kbd
- [ ] Progress（线形 / 环形）、Spinner、Result、Banner

## v0.7.0：导航、布局与手势

- [ ] Sidebar、Breadcrumb、Pagination、Steps
- [ ] ContextMenu、CommandPalette、Anchor
- [ ] Drawer、ActionSheet、ConfirmDialog
- [ ] Container、Grid、Stack、Divider、ScrollArea、SplitPane、AspectRatio、SafeArea
- [ ] SwipeAction、PullToRefresh、InfiniteScroll、IndexBar

## 每批的交付要求

- [ ] 三端代码 + 三种外观
- [ ] 截图测试（三种外观 × 浅色 / 深色 / 增强对比度）
- [ ] 交互测试（每项截图）
- [ ] 各端 README 与设计规范同步更新
- [ ] 输入类组件逐个截图自检（见总原则）
