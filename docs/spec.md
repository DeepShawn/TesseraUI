# TesseraUI 设计规范

> **Tessera**：马赛克镶嵌用的一块块小石片、小瓷砖。每一块都被打磨得圆润，单看朴素，拼在一起才是完整的画面——一份 token 拼出 Apple、Android、Windows、Web 四端一致的界面。

- 版本：v0.1.0
- 日期：2026-11-18
- 目标平台：Apple（iOS / iPadOS / macOS / visionOS）、Android、Windows、Web
- 本文是规范的唯一来源；token 的具体数值以 `tokens/*.json` 为准，本文表格与之保持一致。

---

## 0. 设计语言

### 0.1 四个识别要素

现在常见的 UI 库长得越来越像：冷灰底、靛蓝或紫色主色、全胶囊按钮、毛玻璃、几何无衬线体。TesseraUI 刻意避开这些，用下面四个要素建立自己的面貌。**任何一个组件，都应该能看出其中至少两个。**

| 要素 | 规则 | 体现在 |
|---|---|---|
| **拼贴** | 成组的控件拆成一块块独立的砖，砖之间留 3px 砖缝露出底色，**不用分割线**。整组外角大（14 / 10）、内角小（4） | 列表、分段控制、按钮组、对话框按钮、底部标签栏、统计数字、菜单分隔（一道砖缝） |
| **釉面砖** | 能按的是**凸起的砖**：实色砖顶部一道 1px 釉光、底部 2px 砖厚；浅色砖只有砖厚。能填的是**凹槽**：顶部 1.5px 内阴影。按下时砖**下沉 1px**、砖厚变薄，而不是缩小 | 按钮、图标按钮、复选框、开关滑块 / 输入框、搜索框、开关轨道、分段控制底砖 |
| **软衬线** | 标题用把衬线磨圆的 Fraunces（SOFT 轴 100）配思源宋体；正文用 Instrument Sans 配系统黑体。数字、头像里的字也用衬线 | 所有 title、对话框标题、导航栏标题、统计数字、头像 |
| **矿物色** | 暖调石灰白作底（深色是窑烧炭色），**孔雀釉**是唯一的操作色；朱砂、赭石、青金、紫晶、橄榄五种颜料只做装饰 | 主按钮与选中态用釉色；头像、分类标签、插图用颜料 |

### 0.2 原则

1. **干净**：只有一个操作色；层次靠底色明暗和砖缝区分，不用分割线；只用两种字重。
2. **圆润**：没有尖角，但也不是胶囊——单个控件是圆角方砖，容器用大圆角，圆角采用连续曲率。
3. **有手感**：凸起的按、凹下的填，按下会沉；位移和缩放都用弹簧，拖动跟手，松手继承手指的速度。
4. **一致**：组件只引用语义 token，不写死色值；浅色、深色、增强对比度都靠切换 token 实现。

### 0.3 不做的事

- 毛玻璃不是默认效果：默认关闭，需要时按组件或全局打开（见 1.5）
- 单行控件不用胶囊形；正圆只留给单选
- 不用冷灰和纯黑阴影；不用渐变色按钮
- 颜料色不表示状态，状态色（红、绿、琥珀）不做装饰

## 1. 基础 Token

Token 分三层：

| 层 | 说明 | 例子 |
|---|---|---|
| 原始色板 | 石色、孔雀釉、五种颜料、三种状态色，只给语义 token 引用 | `stone.100`、`glaze.600`、`cinnabar.500` |
| 语义 token | 按用途命名，组件只用这一层 | `bg.surface`、`text.primary` |
| 组件 token | 个别组件的专属值，默认指向语义 token | `button.height.md` |

源文件：`tokens/color.primitives.json`（原始色板）、`tokens/color.semantic.json`（语义颜色）、`tokens/foundation.json`（字体、间距、圆角、拼贴、阴影、层级、断点）、`tokens/motion.json`（动效）。`npm run build` 导出到四端，见第 8 节。

**用色规则**

- 孔雀釉是唯一的操作色：主按钮、选中、链接、焦点都用它。
- 红、绿、琥珀只表示状态，而且总是配图标或文字，不单靠颜色。颜料色只做装饰，不放在按钮和反馈上。
- 实色砖（`*.solid`）在两种模式下用同一个值，保证白字对比度达标；深色下调亮的版本只用于文字、图标和非文字控件。
- 对比度由 `npm run check:contrast` 自动检查，共 284 项全部通过 WCAG AA，报告见 [contrast-report.md](contrast-report.md)：所有文字色在各级底色、输入框底上 ≥ 4.5:1；状态文字、颜料文字在自己的浅底上 ≥ 4.5:1；实色砖上的白字在悬停、按下时仍 ≥ 4.5:1；反色砖上的文字 ≥ 4.5:1；焦点框、实色控件、增强对比度下的描边 ≥ 3:1。占位和禁用色按 WCAG 规定除外。

**增强对比度**

在浅色、深色之外各有一套增强对比度色值，只覆盖需要变化的 token：次要和占位文字各加深一档，`border.subtle` 加强，`border.surface` 和 `border.field` 出现实线描边，开关轨道加深。Windows 例外，见 6.2。

禁用状态：整体 40% 不透明度，不响应悬停和按下。

### 1.3 间距与尺寸

- 基础单位 4px：`space.1` = 4、`space.2` = 8、`space.3` = 12、`space.4` = 16、`space.5` = 20、`space.6` = 24、`space.8` = 32、`space.10` = 40、`space.12` = 48、`space.16` = 64
- 常用值：卡片内边距 20–24，手机页边距 16，区块之间 32–48（展示型页面可到 96）
- 控件高度：`size.sm` 32、`size.md` 40（默认）、`size.lg` 48
- 移动端可点击区域不小于 44×44（看起来可以小，热区要够）
- **拼贴**：`tile.grout` = 3（砖缝宽），`tile.edge` = 2（砖厚）

### 1.4 圆角与形状

| Token | 值 | 用在 |
|---|---|---|
| `radius.grout` | 4 | 拼贴组的内角、单块小砖 |
| `radius.sm` | 6 | 复选框、标签、徽标 |
| `radius.md` | 10 | 按钮、输入框、图标按钮（md 尺寸；sm 用 8，lg 用 12）、开关轨道 |
| `radius.lg` | 14 | 菜单、提示消息、列表等拼贴组的外角、多行文本框 |
| `radius.xl` | 20 | 卡片 |
| `radius.2xl` | 28 | 弹窗、底部抽屉 |
| `radius.full` | 9999 | 只用于单选 |

- **单个控件是圆角方砖，不是胶囊。** 头像是 30% 圆角的方砖；开关轨道 52×30、圆角 10，滑块 24×24、圆角 8（轨道圆角 − 内边距 3 ≈ 8，里外两条弧线平行）。
- **拼贴组外角大、内角小**：组的四个外角用 `lg`（或控件自身的 `md`），砖与砖相邻的内角一律 `grout` 4。
- 圆角采用连续曲率（squircle）：直边转进弯角的地方没有折点。Apple 原生支持（`.continuous`）；Web 暂不启用 `corner-shape`（Chromium 当前实现的边缘抗锯齿不足，放大看有锯齿），先用普通圆角；Android、Windows v0.1 先用普通圆角，v0.2 提供 squircle Shape。
- **砖面质感的画法（防锯齿）**：釉光、砖厚用渐变绘制，跟着圆角一起被裁切；凹槽用带 2px 模糊的内阴影。**不要用不模糊的偏移内阴影**（如 `inset 0 -2px 0`）——它在圆角处会切出两个尖角，看起来有锯齿。各平台同理：Apple 用 `clipShape` 裁切的色带，Android 用 `drawBehind` + `clip`，Windows 用被同圆角 Border 裁切的 Rectangle。
- 嵌套规则：里层圆角 = 外层圆角 − 内边距。

### 1.5 阴影与层级

**阴影**——颜色用 `shadow.color`（浅色是带暖调的墨色，不是纯黑）

| Token | 值（浅色） | 用在 |
|---|---|---|
| `shadow.1` | `0 1px 2px 墨 5%, 0 4px 14px 墨 5%` | 卡片 |
| `shadow.2` | `0 2px 6px 墨 7%, 0 14px 36px 墨 10%` | 菜单、提示消息 |
| `shadow.3` | `0 4px 12px 墨 9%, 0 28px 72px 墨 16%` | 弹窗、底部抽屉 |

深色模式下，各级阴影改为黑色 40% 不透明度，同时卡片和浮层加 1px `border.surface` 描边。

阴影只负责“浮起来”（卡片、浮层）。控件本身的立体感交给砖厚和釉光，不用阴影。

**材质：可选毛玻璃**

- 默认不用毛玻璃：导航栏、标签栏用不透明的 `bg.canvas`，靠一条 `border.subtle` 和下面的内容分开。
- 需要时可以打开：单个组件加 `.ts-glass`，或在根元素上写 `data-material="glass"` 全局打开。适用于导航栏、标签栏、菜单、提示消息，以及开关滑块、分段控制的选中砖。
- 参数：`material.glass` 底色，背景模糊 20px（滑块类 6–8px），饱和度 180%，边缘一圈 `material.glass-rim` 高光。
- 滑块类的毛玻璃会透出下面轨道的颜色；按住时放大成透镜。
- 系统开启“降低透明度”时自动退回不透明底色；浏览器不支持 `backdrop-filter` 时同样退回。
- 各平台对应：Apple 用 `.ultraThinMaterial` / `.regularMaterial`；Windows 用 Acrylic（浮层）、Mica（窗口底）；Android 12+ 用 `RenderEffect` 模糊，更低版本退回不透明底色。

| `z.overlay` | 200 | 遮罩 |
| `z.modal` | 300 | 弹窗、抽屉 |

## 2. 动效

### 2.1 规则

- 位置、大小、缩放用弹簧动画；颜色、透明度用“时长 + 曲线”。
- **按下是“沉”而不是“缩”**：砖往下沉 1px、砖厚从 2px 变 1px，80ms；松手用 snappy 弹回。
- **进场是“落砖”**：从上方 6px、放大 1.5% 落到位并淡入，smooth。
- **成片出现时“铺砖”**：网格按对角线（行号 + 列号）依次出现，每步 30ms，最多错开 8 步。
- 元素越大，回弹越小；整页级别的动画不回弹。
- 退出比进入快，时长约为进入的 70%。
- 同一时间只让一个主要元素在动，其他元素保持静止或只做淡入。
- 只对 transform 和 opacity 做动画，避免页面重新排版。

### 2.2 弹簧 token（质量都取 1）

| Token | 时长 | 回弹 | 刚度 | 阻尼 | 用在 |
|---|---|---|---|---|---|
| `spring.snappy` | 0.3s | 0.15 | 439 | 36 | 按钮回弹、开关、复选框、指示器前沿、动态图标 |
| `spring.smooth`（默认） | 0.4s | 0 | 247 | 31 | 弹窗、抽屉、菜单、卡片展开、页面转场 |
| `spring.bouncy` | 0.5s | 0.25 | 158 | 19 | 提示消息、拖拽松手归位 |

- 换算公式：刚度 = (2π ÷ 时长)²，阻尼 = 4π × (1 − 回弹) ÷ 时长
- 公式由构建脚本计算，表中数值和导出到各平台的数值一致
- SwiftUI：填“时长 + 回弹”，`Animation.spring(duration:bounce:)`
- Jetpack Compose：填“阻尼比（= 1 − 回弹）+ 刚度”，`spring(dampingRatio, stiffness)`
- Windows：Composition 的 `SpringNaturalMotionAnimation` 填“阻尼比 + 周期（= 时长）”；XAML Storyboard 没有弹簧，用 `BackEase` 近似
- Web（JS）：库自带的 `Spring` 类，填“刚度 + 阻尼”，支持打断和初速度
- Web（纯 CSS）：用构建脚本模拟出的 `linear()` 曲线，`--ts-spring-*`；CSS 曲线的时长是弹簧完全停稳的时间（snappy 460ms、smooth 616ms、bouncy 704ms），比“感知时长”长

### 2.3 时长与曲线 token

| Token | 值 | 用在 |
|---|---|---|
| `duration.instant` | 100ms | 悬停、按下时的变色 |
| `duration.fast` | 150ms | 复选框、输入框聚焦、关闭类动画 |
| `duration.normal` | 250ms | 遮罩淡入、内容切换、主题切换 |
| `duration.slow` | 350ms | 不支持弹簧时，给大元素位移用 |
| `ease.standard` | `cubic-bezier(0.2, 0, 0, 1)` | 元素在屏幕内变化 |
| `ease.enter` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 进场，先快后慢 |
| `ease.exit` | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 离场，先慢后快 |
| `ease.linear` | `linear` | 只用于进度条和骨架屏 |

### 2.4 组件动效

| 组件 | 动效 |
|---|---|
| 按钮及所有可点击元素 | 按下 80ms 下沉 1px、砖厚变薄，松手用 snappy 弹回 |
| 开关 | 可以点，也可以按住滑块左右拖：拖动 1:1 跟手，拖出两端有橡皮筋阻力；拖过中线时轨道先变色，提示松手后的结果；松手按位置（过半）或速度（> 500px/s 朝甩的方向）决定开关，滑块用 snappy 弹到位。按住时滑块横向拉宽 6px，开启时向左长。轨道里有开（竖线）/ 关（小圆圈）标记，不只靠颜色区分 |
| 复选框 | 150ms 填色，勾号从左往右描出来 |
| 单选 | 中间的小方砖从 −45° 转正并放大，snappy |
| 输入框 | 聚焦时 150ms 内底色变成 `bg.surface`，`focus.glow` 光晕从 0 扩到 3px |
| 下拉菜单 | 从触发位置展开（从 0.96 缩放到 1 并淡入），smooth；关闭时只淡出，150ms |
| 弹窗 | 遮罩 250ms 淡入；面板从 0.96 缩放到 1 并淡入，smooth；关闭 150ms，缩到 0.98 并淡出 |
| 底部抽屉 | smooth 滑入；拖动跟手，松手按 2.5 的规则停到档位 |
| 选中指示器（标签页、分段控制） | 朝移动方向的那条边用 snappy，另一条边用 smooth；两边速度不同，移动时自然拉长，到位后收拢。分段控制的选中砖是一块墨色釉面砖，在底砖之间滑过，圆角跟随落脚的那块砖（首尾外角大）；也可以按住选中砖左右拖到别的选项上，松手落到最近的一块，甩得够快就朝甩的方向走一块。细条指示器用 scaleX 拉长；选中砖改宽度，因为 scaleX 会压扁圆角——它是绝对定位元素，改宽度不会引起页面重排 |
| 提示消息 | 反色砖从顶部落下，同时从 0.9 放大到 1，bouncy；停留 3 秒（带操作按钮的 5 秒）；可以上滑甩掉；离场 150ms |
| 卡片展开 | 位置、尺寸、圆角（20→0）一起过渡，smooth；详情内容晚 50ms 淡入；可以下拉手势返回 |
| 列表、网格进场 | 落砖；列表每块错开 30ms，网格按对角线错开，最多 8 步 |
| 骨架屏 | 光带 1.5 秒扫一次，linear 循环 |
| 动态图标 | 菜单↔关闭、播放↔暂停、勾选、收藏做变形动画，snappy |

### 2.5 手势

- 拖动时元素和手指 1:1 同步移动，不加任何缓动。
- 松手时把手指当时的速度交给弹簧作为初速度。“流畅感”主要来自这一步。
- 松手速度超过 500px/s，就朝滑动方向切到下一档；没超过就停到最近的档位。
- 拖出边界后阻力越来越大，像拉橡皮筋。

## 3. 深色模式

色值见 1.1，本节是规则。

- 两套主题叫“石灰”（浅色）和“夜窑”（深色）：都是暖调，夜窑是窑烧后的炭色，不是冷灰。
- 深色模式不是把颜色反过来，而是“越靠前的层越亮”：页面底 → 卡片 → 浮层 → 浮层上的浮层，依次变亮，用亮度代替阴影表现层级。砖缝（页面底）始终最暗，所以拼贴在深色下依然清楚。
- 背景不用纯黑，文字不用纯白（石白 #F0ECE4）：看着不刺眼，OLED 屏滚动时也不容易拖影。
- 卡片和浮层加 1px `border.surface` 描边，把边界勾出来；阴影规则见 1.5。
- 釉光、砖厚在深色下保留，只调不透明度。
- 主题三选一：石灰、夜窑、跟随系统，默认跟随系统。
- 切换主题时整屏做一次 250ms 交叉淡化，不让每个组件各自过渡颜色。
- 图标颜色跟随文字色（currentColor）；插图和品牌图形另外准备深色版本。
- 状态栏文字颜色跟随当前主题；Windows 标题栏随主题切换深浅色。

## 4. 图标（全部自己画）

### 4.1 绘制规格

- 画布 24×24，四周各留 2px，图形画在中间 20×20 的区域里
- 线条 1.5px，线头和转角都是圆的；图标里的方形带 2px 小圆角，和组件的圆润感一致
- 基准形状：圆形直径 20，正方形 18×18，竖长方形 16×20，横长方形 20×16。按这些尺寸画，不同形状的图标看起来才一样大
- 尺寸：16、20、24 三档。16px 单独画一版，线条不变细，同时删减细节，免得糊成一团
- 样式：线性（默认）和实心（选中状态）。例如底部标签栏里，选中的图标从线性切换成实心
- 颜色：单色，跟随文字颜色（currentColor）
- 同一类图标的细节量保持一致，例如所有文件类图标的折角大小相同

### 4.2 首批范围（约 150 个）

| 通讯 | 消息、电话、邮件、通知、评论 |

### 4.3 命名与交付

- 命名：小写英文加短横线，实心版加后缀 `-fill`，例如 `heart` 和 `heart-fill`

## 6. 原生控件重绘

**原则**：外观完全自己画，底层尽量沿用原生元素，保留键盘操作、读屏软件和输入法支持。

### 6.1 Web 端

| 原生控件 | 处理方式 |
|---|---|
| 滚动条 | 6px 宽的细条（4px 圆角），平时隐藏，滚动时出现，鼠标移上去变宽到 10px |
| 下拉选择 `<select>` | 触发框用凹槽输入框样式，弹出列表用库里的菜单；手机上改成从底部抽屉里选 |
| 日期、时间输入 | 桌面上弹出日历；手机上在底部抽屉里放滚轮选择器 |
| 复选框、单选、滑块、进度条、文件选择按钮 | 换成库里的组件 |
| 数字输入框的上下小箭头、搜索框自带的 × | 去掉，换成自己的按钮 |
| 选中文字、输入光标 | 选中底色用主色 20%，光标用主色 |
| 自动填充底色 | 浏览器自动填充时出现的黄色或蓝色底，改回输入框底色 |
| 悬停提示（title 属性） | 换成库里的工具提示 |
| `alert()`、`confirm()` | 一律不用，改用库里的对话框 |

### 6.2 App 端

**Apple、Android 通用**

- 开关、分段控制、滚轮选择器、日期和时间选择器
- 警告框、底部操作面板、长按菜单
- 导航栏和底部标签栏。自己画导航栏时，返回手势要一起重新实现：iOS 的边缘右滑返回；Android 13+ 的预见式返回（Predictive Back）
- 下拉刷新的指示器
- 键盘上方的工具条（上一项 / 下一项 / 完成）

**Windows（WinUI 3）**

- 按钮、文本框、下拉框、复选框、开关等：通过重写控件模板（ControlTemplate）换外观，保留 WinUI 控件本身的键盘、UI 自动化（读屏）和输入法支持
- 焦点框：用 WinUI 自带的焦点视觉（FocusVisual），把颜色、粗细、间隙改成 5.1 的规格
- 右键菜单（ContextFlyout / MenuFlyout）、工具提示：改圆角、材质和动效
- 标题栏：扩展内容到标题栏（`ExtendsContentIntoTitleBar`），保留系统的最小化、最大化、关闭按钮
- 滚动条：WinUI 默认已是细条、悬停变宽，只改颜色
- **对比度主题**：Windows 的高对比度由用户自选整套配色，应用必须改用系统色（`SystemColorWindowColor` 等），不能用自己的色值。TesseraUI 的 `HighContrast` 主题字典已把每个语义 token 映射到对应的系统色；此时叠加层、阴影、砖厚、釉光全部关闭

### 6.3 改不了、也不建议改的

系统键盘、权限申请弹窗、系统分享面板、相册和文件选择器、支付弹窗、系统通知的样式；Windows 上还有用户账户控制（UAC）弹窗、系统文件对话框、通知中心的通知样式、窗口外框。这些由操作系统控制，只需要让自己的界面和它们衔接自然。

### 6.4 中文输入法

自己画的输入框必须正确处理 composition 事件：打拼音、还没选定汉字的这段时间里，不能触发搜索、校验或字数统计，按回车也不能提交表单。否则拼音字母会被当成真正的输入内容。

- Web：库提供 `onCommittedInput()` 和 `guardEnterWhileComposing()`；Safari 在选字结束后会补发一次 keyCode 229 的回车，也要拦掉
- Apple：`UITextInput.markedTextRange` 不为空时视为正在输入
- Android：`TextFieldValue.composition` 不为空时视为正在输入
- Windows：`TextBox.TextCompositionStarted` / `TextCompositionEnded` 事件

## 7. 无障碍

- 对比度：正文 ≥ 4.5:1，大字和图标 ≥ 3:1（1.1 的色值已满足）
- 键盘：所有操作都能只用键盘完成，焦点顺序和视觉顺序一致，聚焦样式见 5.1
- 读屏：自己画的控件要补齐角色、名称和状态，例如开关要读出“已开启”或“已关闭”。对应接口：VoiceOver（Apple）、TalkBack（Android）、讲述人 / UI Automation（Windows）、ARIA（Web）
- 减弱动态效果：系统开启后，去掉位移、缩放和视差，统一改成 150ms 淡入淡出，骨架屏停止扫光。对应系统设置：Apple“减弱动态效果”、Android“移除动画”、Windows“动画效果”、Web `prefers-reduced-motion`
- 增强对比度：系统开启后，输入框和卡片补上 1px 描边，次要文字的对比度提高一档
- 触控：可点击区域不小于 44×44
